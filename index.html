TSV import – elvárt struktúra
Kötelező oszlopok (legalább ezek):
  • Dátum (fejléc lehet: date / Dátum / Datum)
  • Összeg (fejléc lehet: amount / Összeg / Osszeg)
  • Jogcím (fejléc lehet: title / Jogcím / Jogcim)
Opcionális oszlopok (ha vannak, betöltjük):
  • Hónap: month / Hónap / Honap (ha nincs, a dátumból számoljuk)
  • Kategória: category / Kategória / Kategoria
  • Fizetési mód: payment_type / Típus / Tipus
  • Tranzakció jelleg: transaction_type / Jelleg (pl. Kiadás / Bevétel)
  • Kivonat sor: statement_item / Kivonat sor / Kivonatsor
Formátum szabályok:
  • Elválasztó: ; vagy , (automatikus detektálás)
  • Dátum: YYYY-MM-DD vagy YYYY.MM.DD vagy YYYY.MM.DD.
  • Összeg: lehet 1 234, 1 234,56, 1234.56, „Ft” szöveg is lehet benne
  • Előjel: ha megadod a Jelleg-et (Kiadás/Bevétel), akkor a rendszer ahhoz igazítja az előjelet
Példa (pontos fejlécnevek és tipikus magyar formátum): 
Dátum;Összeg;Jogcím;Kategória;Típus;Jelleg;Kivonat sor
    2026.01.10.;12 500;Élelmiszer;Bolt;Kártya;Kiadás;OTP 123
    2026-01-12;250 000;Fizetés;Bér;Utalás;Bevétel;Employer
